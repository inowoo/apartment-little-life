# apartment-little-life

横から見た大きなマンションで、住人たちの生活を眺め、少しだけ介入できる「生活観察ゲーム」の試作プロジェクトです。

この `README.md` を **現時点の仕様書・操作説明・実装状況・変更履歴の正本** とします。今後コードを変更するときは、仕様に関係する変更を必ずこのREADMEにも反映します。

## ゲームの核

- 5階建て × 各階5部屋、計25部屋のマンションを横から眺める。
- 住人はそれぞれ固有の外見・名前・職業・性格・生活スケジュール・思考を持つ。
- 朝・昼・夕方・夜・深夜が連続して巡り、住人は出勤、通学、家事、食事、睡眠などを行う。
- 人物を選ぶと、現在の行動、考えていること、プロフィール、観察履歴を確認できる。
- 将来的には、住人へ直接命令するのではなく、環境や物へ「ちょっかい」を出すことで行動や人間関係、物語の結果を変えられるようにする。
- 住人のストーリーは一本道ではなく、状態・人間関係・偶然・プレイヤー介入で分岐する方向を目指す。

## 対応環境

Webブラウザで動作することを前提とします。

- Windows PC: Chrome / Edge 系ブラウザを主対象
- iPad: Safari を主対象
- レスポンシブ表示
- マウスとタッチの両方を Pointer Events ベースで扱う

## 操作方法

### Windows / マウス

- 左クリック: 住人を選択
- 左ドラッグ: 画面をパン
- マウスホイール: 拡大・縮小
- `画面を戻す`: 初期カメラ位置へ戻す
- `一時停止`: 時間進行の停止 / 再開
- `速度`: 時間進行速度を変更

### iPad / タッチ

- タップ: 住人を選択
- 1本指スワイプ: 画面をパン
- 2本指ピンチ: 拡大・縮小
- 小さな対象を正確にドラッグする操作は、基本操作として要求しない方針

## 現在の試作仕様

### マンション

- 5階建て
- 1フロア5部屋
- 101〜105、201〜205 ... 501〜505 の25部屋
- サイドビューのドールハウス風表示

### 時間

- ゲーム内時刻が連続して進行
- 朝 / 昼 / 夕方 / 夜 / 深夜で背景の雰囲気が変化
- 一時停止可能
- 時間速度変更可能

### 住人

初期試作では複数の住人を固定データで用意し、生活時間の違いを確認できるようにします。

例:

- 会社員
- 小学生
- 在宅勤務
- 老夫婦
- 大学生
- 夜勤勤務
- 引きこもり
- 漫画家

住人は色だけに依存せず、名前・シルエット・記号などでも見分けられる方向で設計します。

### 選択・観察

住人を選択すると以下を表示します。

- 名前
- 部屋番号
- 職業 / 立場
- 現在地
- 現在の行動
- 現在考えていること
- 簡易プロフィール
- 観察履歴（試作段階では簡易ログ）

## プレイヤー介入（計画中）

基本思想は「直接命令ではなく、世界を少し変えて結果を見る」です。

### 小さな介入の例

- 玄関前に物を置く
- 傘を隠す
- 目覚まし時刻を少し変える
- 郵便物や宅配を別の場所へ動かす
- 共用部に落とし物を置く

### 中規模の介入の例

- エレベーターを一時停止させる
- 一時的な停電
- Wi-Fi障害
- 宅配の誤配
- 掲示板へ張り紙を出す

### 大きな介入の例

- 雨 / 雪 / 猛暑など天候を変える
- 電車遅延
- 学校や会社の臨時休業
- 近所のイベント発生

同じ介入でも、住人の性格、現在の心理状態、人間関係、時刻、過去の出来事によって反応が変わる設計を目指します。

## ストーリー / AI方針

ストーリー全体をリアルタイム生成AIへ丸投げせず、ゲーム側で整合性を持つ状態を管理する方針です。

想定構造:

1. キャラクター設定
2. 生活スケジュール
3. 心理状態
4. 人間関係
5. 進行中ストーリーと段階
6. 現在の出来事
7. 上記を材料に台詞・独り言の候補を生成

これにより、AIらしい台詞の変化を持たせつつ、人物設定や物語が毎回破綻しにくい構造を目指します。

## 技術方針

初期試作は、まず仕組みの面白さを確認するため、依存ライブラリのない HTML / CSS / JavaScript + Canvas 2D で実装します。

理由:

- PCとiPadの両方ですぐ試せる
- ビルド工程なしでGitHub Pagesへ載せやすい
- 入力、カメラ、時間、住人シミュレーションの試作が軽い
- ゲーム規模が増えた場合は PixiJS 等へ移行可能
