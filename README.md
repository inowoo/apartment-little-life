# apartment-little-life

横から見た大きなマンションで、住人たちの生活を眺め、少しだけ介入できる「生活観察ゲーム」の試作プロジェクトです。

現在のバージョン: **v0.2.0**

この `README.md` を **現時点の仕様書・操作説明・実装状況・変更履歴の正本** とします。今後コードを変更するときは、仕様に関係する変更を必ずこのREADMEにも反映します。

## ゲームの核

- 5階建て × 各階5部屋、計25部屋のマンションを横から眺める。
- 住人はそれぞれ固有の外見・名前・職業・性格・生活スケジュール・思考を持つ。
- 朝・昼・夕方・夜・深夜が連続して巡り、住人は出勤、通学、家事、食事、睡眠などを行う。
- 人物を選ぶと、現在の行動、考えていること、プロフィール、生活ログを確認できる。
- 住人を選択していない間も生活は進み、行動や居場所が変わった時点を人物ごとに自動記録する。
- 将来的には、住人へ直接命令するのではなく、環境や物へ「ちょっかい」を出すことで行動や人間関係、物語の結果を変えられるようにする。
- 住人のストーリーは一本道ではなく、状態・人間関係・偶然・プレイヤー介入で分岐する方向を目指す。

## ビジュアル方針

- スーパーファミコン期のゲームを思わせる、低解像度のドット絵風表現を基本とする。
- アンチエイリアスを抑え、輪郭や家具も角の立ったピクセル表現に寄せる。
- 住人は色だけでなく、髪型・服・体格・アクセント色・名前で見分けられるようにする。
- 住人の状態に応じて、立つ / 忙しく動く / 座る / PC・作業 / 寝る、などの表示パターンを切り替える。
- 今後は住人ごとにさらに複数の服装、表情、持ち物、移動アニメーションを増やす。

## 対応環境

Webブラウザで動作することを前提とします。

- Windows PC: Chrome / Edge 系ブラウザを主対象
- iPad: Safari を主対象
- レスポンシブ表示
- マウスとタッチの両方を Pointer Events ベースで扱う

## 操作方法

### Windows / マウス

- 左クリック: 住人を選択
- 左ドラッグ: 画面をパン
- マウスホイール: 拡大・縮小
- `画面を戻す`: 初期カメラ位置へ戻す
- `一時停止`: 時間進行の停止 / 再開
- `速度`: 時間進行速度を変更

### iPad / タッチ

- タップ: 住人を選択
- 1本指スワイプ: 画面をパン
- 2本指ピンチ: 拡大・縮小
- 小さな対象を正確にドラッグする操作は、基本操作として要求しない方針

## タイトル画面

起動時にタイトル画面を表示します。

- タイトル: `APARTMENT LITTLE LIFE`
- 現在のバージョンを表示
- `生活をのぞく` ボタンでゲーム開始
- タイトル画面表示中はゲーム内時間を進めない

## 現在の試作仕様

### マンション

- 5階建て
- 1フロア5部屋
- 101〜105、201〜205 ... 501〜505 の25部屋
- サイドビューのドールハウス風表示
- 各部屋に簡易家具を配置
- 住人が外出中の部屋には外出人数を表示

### 時間

- ゲーム内時刻が連続して進行
- 朝 / 昼 / 夕方 / 夜 / 深夜で背景の雰囲気が変化
- 一時停止可能
- 時間速度は x0.5 / x1 / x4 / x12 を切り替え可能
- 現在はリアル1秒 = ゲーム内5分（x1時）

### 住人

初期試作では12人の固定住人を用意し、生活時間の違いを確認できるようにしています。

- 会社員
- 帰宅の遅い会社員
- 小学生
- 在宅勤務
- 老夫婦
- 大学生
- 夜勤勤務
- 引きこもり
- 漫画家
- 留学生
- フリーランス

各住人は現在、個別の配色・髪型・体格パターンを持ちます。

### 簡易生活スケジュール

住人の職業・立場ごとに、時刻に応じて以下のような状態へ切り替わります。

- 睡眠
- 朝の支度
- 出勤 / 通学
- 仕事 / 授業
- 買い物 / 散歩
- 在宅勤務
- 自由時間
- 夜勤
- 漫画制作
- PC / オンライン活動

外出中の住人はマンション画面から一時的にいなくなります。

### 選択・生活ログ

住人を選択すると以下を表示します。

- 名前
- 部屋番号
- 職業 / 立場
- 現在地
- 現在の行動
- 現在考えていること
- 簡易プロフィール
- 生活ログ

生活ログは、プレイヤーがその住人を選択していたかどうかに関係なく、自動で蓄積します。

記録対象:

- 行動が変わった時刻
- その時点の居場所
- その時点の行動
- 内部的にはその時点の思考も保持

各住人について最大80件を保持し、人物パネルでは直近30件を表示します。

## プレイヤー介入（計画中）

基本思想は「直接命令ではなく、世界を少し変えて結果を見る」です。

### 小さな介入の例

- 玄関前に物を置く
- 傘を隠す
- 目覚まし時刻を少し変える
- 郵便物や宅配を別の場所へ動かす
- 共用部に落とし物を置く

### 中規模の介入の例

- エレベーターを一時停止させる
- 一時的な停電
- Wi-Fi障害
- 宅配の誤配
- 掲示板へ張り紙を出す

### 大きな介入の例

- 雨 / 雪 / 猛暑など天候を変える
- 電車遅延
- 学校や会社の臨時休業
- 近所のイベント発生

同じ介入でも、住人の性格、現在の心理状態、人間関係、時刻、過去の出来事によって反応が変わる設計を目指します。

## ストーリー / AI方針

ストーリー全体をリアルタイム生成AIへ丸投げせず、ゲーム側で整合性を持つ状態を管理する方針です。

想定構造:

1. キャラクター設定
2. 生活スケジュール
3. 心理状態
4. 人間関係
5. 進行中ストーリーと段階
6. 現在の出来事
7. 上記を材料に台詞・独り言の候補を生成

これにより、AIらしい台詞の変化を持たせつつ、人物設定や物語が毎回破綻しにくい構造を目指します。

## 技術方針

初期試作は、依存ライブラリのない HTML / CSS / JavaScript + Canvas 2D で実装しています。

- PCとiPadの両方ですぐ試せる
- ビルド工程なしでGitHub Pagesへ載せやすい
- Canvasの `imageSmoothingEnabled = false` を使い、ドット絵風の描画を維持する
- ゲーム規模が増えた場合は PixiJS 等へ移行可能

現在の主なファイル:

- `index.html`: タイトル画面、HUD、人物パネル
- `styles.css`: PC / iPad向けレスポンシブUI
- `src/main.js`: Canvas描画、時間、住人、生活ログ、入力、ドット絵キャラクター
