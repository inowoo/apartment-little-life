# apartment-little-life

横から見た大きなマンションで、住人たちの生活を眺め、少しだけ介入できる「生活観察ゲーム」の試作プロジェクトです。

現在のバージョン: **v0.2.1**

この `README.md` を **現時点の仕様書・操作説明・実装状況・変更履歴の正本** とします。今後コードを変更するときは、仕様に関係する変更を必ずこのREADMEにも反映します。

## ゲームの核

- 5階建て × 各階5部屋、計25部屋のマンションを横から眺める。
- 住人はそれぞれ固有の外見・名前・職業・性格・生活スケジュール・思考を持つ。
- 朝・昼・夕方・夜・深夜が巡り、住人は出勤、通学、家事、食事、睡眠などを行う。
- 人物を選ぶと、現在の行動、考えていること、プロフィール、生活ログを確認できる。
- 選択していない住人についても、行動や居場所が変わった時点を自動記録する。
- 将来的には、住人へ直接命令するのではなく、環境や物へ「ちょっかい」を出すことで行動や人間関係、物語の結果を変えられるようにする。

## ビジュアル方針

- スーパーファミコン期を思わせる低解像度ドット絵風表現。
- Canvas のアンチエイリアスを抑え、住人や家具を角の立ったピクセル表現に寄せる。
- 住人ごとに髪型・服・体格・配色を変え、見分けやすくする。
- 行動に応じて、立つ / 歩く / 座る / 作業 / 睡眠などの表示パターンを切り替える。
- 今後は服装、表情、持ち物、生活アニメーションの差分を増やす。

## 対応環境

Webブラウザで動作します。

- Windows PC: Chrome / Edge 系ブラウザを主対象
- iPad: Safari を主対象
- マウスとタッチの両方を Pointer Events ベースで扱う
- `visualViewport` を利用し、ブラウザの実表示領域へ自動フィットする

## 画面フィット仕様

- 起動時にマンション全体がブラウザ画面へ収まる縮尺を自動計算する。
- ウィンドウサイズ変更時も自動で再フィットする。
- iPadなどで画面を回転した場合も再フィットする。
- SafariなどでアドレスバーやブラウザUIによって表示領域が変わった場合は `visualViewport` を基準に再計算する。
- 画面上部のHUDと下部UIのために安全余白を確保する。
- 狭い画面では従来の固定最小ズーム値に縛られず、必要なだけ縮小して全体表示する。
- `画面を戻す` ボタンでも、その時点のブラウザサイズに合わせて再フィットする。
- 全体表示後もマウスホイール / ピンチで拡大し、ドラッグ / スワイプで任意の場所を見ることができる。

## 操作方法

### Windows / マウス

- 左クリック: 住人を選択
- 左ドラッグ: 画面をパン
- マウスホイール: 拡大・縮小
- `画面を戻す`: 現在のブラウザサイズに合わせてマンション全体を再フィット
- `一時停止`: 時間進行の停止 / 再開
- `速度`: 時間進行速度を変更

### iPad / タッチ

- タップ: 住人を選択
- 1本指スワイプ: 画面をパン
- 2本指ピンチ: 拡大・縮小
- 縦横回転時は自動で再フィット
- 小さな対象を正確にドラッグする操作は基本操作として要求しない

## タイトル画面

- バージョン表示
- `生活をのぞく` ボタンで開始
- タイトル画面表示中はゲーム内時間を進めない

## 現在の試作仕様

### マンション

- 5階建て
- 1フロア5部屋
- 101〜105、201〜205 ... 501〜505 の25部屋
- サイドビューのドールハウス風表示
- 各部屋に簡易家具を配置
- 外出中の住人がいる部屋には外出人数を表示

### 時間

- ゲーム内時刻が連続して進行
- 朝 / 昼 / 夕方 / 夜 / 深夜で背景が変化
- 一時停止可能
- 時間速度は x0.5 / x1 / x4 / x12
- x1時はリアル1秒 = ゲーム内5分

### 住人

初期試作では12人の固定住人を用意しています。

- 会社員
- 帰宅の遅い会社員
- 小学生
- 在宅勤務
- 老夫婦
- 大学生
- 夜勤勤務
- 引きこもり
- 漫画家
- 留学生
- フリーランス

### 簡易生活スケジュール

職業・立場ごとに時刻に応じて状態が切り替わります。

- 睡眠
- 朝の支度
- 出勤 / 通学
- 仕事 / 授業
- 買い物 / 散歩
- 在宅勤務
- 自由時間
- 夜勤
- 漫画制作
- PC / オンライン活動

外出中の住人はマンション画面から一時的にいなくなります。

### 選択・生活ログ

住人を選択すると以下を表示します。

- 名前
- 部屋番号
- 職業 / 立場
- 現在地
- 現在の行動
- 現在考えていること
- 簡易プロフィール
- 生活ログ

生活ログはプレイヤーが見ていない間も自動で蓄積します。

- 行動が変わった時刻
- その時点の居場所
- その時点の行動
- 1人あたり最大80件保持
- 人物パネルでは直近30件を表示

## プレイヤー介入（計画中）

基本思想は「直接命令ではなく、世界を少し変えて結果を見る」です。

小さな介入例:

- 玄関前に物を置く
- 傘を隠す
- 目覚まし時刻を少し変える
- 郵便物や宅配を別の場所へ動かす
- 共用部に落とし物を置く

中規模の介入例:

- エレベーター停止
- 一時的な停電
- Wi-Fi障害
- 宅配の誤配
- 掲示板への張り紙

大きな介入例:

- 雨 / 雪 / 猛暑などの天候変更
- 電車遅延
- 学校や会社の臨時休業
- 近所のイベント発生

同じ介入でも、住人の性格、心理状態、人間関係、時刻、過去の出来事によって反応が変わる設計を目指します。

## ストーリー / AI方針

ストーリー全体を生成AIへ丸投げせず、ゲーム側で整合性を管理します。

想定構造:

1. キャラクター設定
2. 生活スケジュール
3. 心理状態
4. 人間関係
5. 進行中ストーリーと段階
6. 現在の出来事
7. 上記を材料に台詞・独り言候補を生成

## 技術方針

初期試作は依存ライブラリなしの HTML / CSS / JavaScript + Canvas 2D で実装しています。

- PCとiPadの両方ですぐ試せる
- ビルド工程なしでGitHub Pagesへ載せやすい
- `imageSmoothingEnabled = false` でドット絵風描画を維持
- Pointer Events でマウスとタッチを共通化
- `visualViewport` で実表示領域を取得
- 規模が増えた場合は PixiJS 等への移行を検討

主なファイル:

- `index.html`: タイトル画面、HUD、人物パネル
- `styles.css`: PC / iPad向けUI
- `src/main.js`: Canvas描画、時間、住人、生活ログ、入力、カメラ、ドット絵キャラクター
